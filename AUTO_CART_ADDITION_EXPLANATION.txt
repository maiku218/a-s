AUTOMATIC CART ADDITION ON BARCODE SCAN - EXPLANATION

FILE: templates/cashier_dashboard.html
FUNCTION: processScan(barcode) - lines ~709-735

HOW IT WORKS:

1. TRIGGER: When a barcode is scanned (input of 6+ digits), the scanner.addEventListener('input') calls processScan(buffer)

2. FETCH PRODUCT DATA: 
   - Calls `/get_product/${barcode}` endpoint
   - Returns product details if barcode exists

3. CART LOGIC:
   - If product exists in data:
     * Get current stock: `const max = p.stock;`
     * Find if item already in cart: `const idx = cart.findIndex(i => i.id === p.id);`
     * Get current quantity if exists: `const curQty = idx >= 0 ? cart[idx].quantity : 0;`
     * Calculate new total: `const totalQty = curQty + 1;`
     
     * STOCK VALIDATION:
       - If totalQty > max: Show "No stock" alert and return
       
     * CART UPDATE:
       - IF ITEM ALREADY IN CART (idx >= 0):
         `cart[idx].quantity += 1;`  // Increment quantity by 1
       - ELSE (ITEM NOT IN CART):
         `cart.push({ id: p.id, name: p.name, price: p.price, expiry: p.expiry || null, quantity: 1 });`  // Add new item

4. UPDATE DISPLAY:
   - Calls `renderCart()` to refresh cart sidebar display
   - Calls `logScan()` to log the scan activity

SUMMARY:
The system automatically adds scanned items to the cart by:
- Checking if item already exists in cart
- If yes: incrementing quantity by 1
- If no: adding new item with quantity 1
- Then updating the cart display immediately

This creates the "automatic go to current cart" behavior when scanning barcodes.
