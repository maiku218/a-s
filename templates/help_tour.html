Welcome to PharmaCon Help Tour

Learn how to use the system with our interactive guide

The Help Tour is an interactive guide that walks you through every page and feature of the PharmaCon system. It uses visual highlights, tooltips, and step-by-step instructions to help you understand each component.

?
Floating Help Button
Look for the blue ? HELP button at the bottom-right corner of every page. Click it to open the help menu and start the tutorial from any page.
▸
Interactive Spotlight
When the tour is active, a dark overlay appears with a spotlight highlighting the current element. An arrow points from the tooltip to the highlighted area.
📋
Step-by-Step Guide
Each step shows a title, description, and instruction. Navigate using the buttons or keyboard shortcuts. Your progress is saved automatically.
🔒
Progress Saved
The system remembers if you completed the tour or which step you were on. You can resume later without starting over. The pulse animation stops after completion.
⚙
Page-Specific Tours
Every page has its own set of tour steps tailored to that page's features. The help button is available on all admin and cashier pages.
⌨
Keyboard Shortcuts
Use keyboard shortcuts to navigate quickly. Press ESC to exit anytime, Enter or Right Arrow for next step, Left Arrow for previous step.

How to Start the Tour

Follow these simple steps to begin

1
Locate the Help Button
Find the blue circular button with a question mark (?) at the bottom-right corner of the screen. It may have a subtle pulse animation.
2
Open the Help Menu
Click the help button to reveal a dropdown menu with options like "Start Tutorial" or "Restart Tutorial".
3
Begin the Tutorial
Click "Start Tutorial" to launch the interactive tour. The screen will dim and the first element will be highlighted.
4
Navigate Through Steps
Use the Next and Previous buttons in the tooltip, or use keyboard shortcuts to move through each step.
5
Complete or Skip
Click Finish on the last step to complete the tour, or click Skip to exit anytime. You can restart the tour later from the help menu.

Troubleshooting

Common issues and how to resolve them

!
Tour not appearing
Make sure help-tour.js and help-tour.css are properly loaded. Check the browser console for errors.
!
Overlay stuck on screen
Press ESC to close the tour instantly. If that doesn't work, refresh the page.
!
Pulse animation not showing
The tour may already be marked as completed. Open the Help Menu and select "Restart Tutorial" to reset.
!
Elements not highlighted
Ensure the page element has the correct ID or selector matching the tour configuration for that page.
